# ISO/IEC 27001:2022-aligned evidence themes

This project uses high-level ISO/IEC 27001:2022 Annex A themes as an evidence-mapping aid. It does not reproduce the standard and does not claim certification.

Examples:
- Identity and access management: local users, privileged groups, account lifecycle evidence
- Logging and monitoring: Security event log health and authentication/account events
- Malware protection: Microsoft Defender status
- Network security: Windows Firewall, network profiles, listening ports
- Secure configuration: UAC, SMBv1, Secure Boot, BitLocker, services
- Documented information: collection metadata and evidence manifest
